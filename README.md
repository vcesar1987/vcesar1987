## 🇺🇸 English

### 👋 About me

Computer engineer with 10+ years in tech and 4+ years leading end-to-end **OMS SaaS implementations** for enterprise retail in Chile. I connect e-commerce platforms, ERPs, marketplaces, POS systems and logistics carriers through REST APIs and webhooks, and I work in English and Spanish as the technical bridge between Engineering, Product and the business, from discovery through go-live and adoption.

These days I also build:

- 🤖 **AI agents & MCP servers** with Claude and Claude Code to automate implementation and support work
- 🔁 **Workflow automation** with n8n, GitHub Actions and Python
- 📡 **Proactive monitoring** that catches integration failures before customers do

### 💼 Work highlights · BeFlow (2022 – present)

- **8+ enterprise OMS implementations**, handling 3–4 clients at once: Sparta, Grupo Depor (Converse, Steve Madden, Umbro), Kayser, ASW Group, Trailstore, All Nutrition, Grupo Titanio (Bubba) and Mascotas Latinas (~70 stores).
- **Leading Sparta's Multi-Fulfillment project**, one of the most complex implementations in BeFlow's history, after taking over a 2+ year account that had no documentation. Along the way I traced a production bug to the Nomad courier API ignoring `pickupReadyDate` and pushed the vendor to fix it.
- **Platform and ERP migrations:** FLAP → BeFlow, VTEX → Shopify, SAP B1 direct integration through Service Layer, BesDTE → Facele (e-invoicing) and RPro9 → Prism (POS).
- **Advanced fulfillment flows:** BOPIS, same-day express, cross-docking, fulfillment by seller and regional hub consolidation for last-mile delivery.
- **Manual → automated:** courier label generation, SAP B1 invoicing and credit notes.
